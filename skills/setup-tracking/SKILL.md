---
name: setup-tracking
description: Set up PixelFlow on a site. Use when the user wants to install PixelFlow, add the pixel, connect Meta or TikTok, or track a new conversion.
---

Follow the PixelFlow server manual from initialize. Call get_site_status and do only next_action. When next_action.say is set, say that and wait. Do not invent a snippet, a pixel id, or a token. The snippet's apiKey and siteId are public. Creating or deleting a trigger waits for one approval.
